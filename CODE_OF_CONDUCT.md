# SONIC Code of Conduct

## Our standard

SONIC contributors are expected to communicate professionally, act in good faith, and focus technical discussions on evidence, engineering trade-offs, and the project mission.

Unacceptable behaviour includes harassment, discrimination, personal attacks, deliberate disruption, doxxing, publication of private information, and knowingly submitting malicious code or credentials.

## Technical disagreement

Strong technical disagreement is allowed and encouraged when it is constructive.

Prefer:

- reproducible evidence;
- benchmarks;
- tests;
- documented trade-offs;
- focused review comments.

Avoid personal criticism or arguments about status.

## Maintainer responsibility

Maintainers may moderate discussions, reject contributions that violate project standards, and restrict participation when necessary to protect contributors or the project.

## Reporting problems

Report serious conduct concerns privately to the repository maintainers rather than creating a public issue containing sensitive information.
